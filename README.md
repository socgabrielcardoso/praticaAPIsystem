# Pratica API System

Laboratório defensivo de **API Security** construído em Python para praticar validação, comportamento seguro, testes e análise de controles em cenários autorizados.

## Objetivo
Explorar como APIs devem autenticar, autorizar, validar entradas, limitar abuso, registrar eventos e responder de forma previsível.

## Stack
- Python
- Pytest
- Docker
- configuração por ambiente

## Foco
- API Security
- Blue Team
- AppSec
- Secure Validation
- Security Testing
- Logging

Use apenas dados sintéticos e ambientes próprios ou autorizados. A documentação em `docs/professional/` registra os padrões técnicos do laboratório.
